# House Price Prediction

## Project Overview

This project predicts house prices using Machine Learning and Linear Regression.

## Dataset

The dataset contains house-related features such as:

- OverallQual
- GrLivArea
- GarageCars
- TotalBsmtSF
- YearBuilt
- FullBath
- BedroomAbvGr
- LotArea
- SalePrice

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib
- Jupyter Notebook

## Machine Learning Model

Linear Regression is used to predict the SalePrice of houses.

## Steps Performed

1. Loaded the dataset
2. Explored the dataset
3. Checked missing values
4. Selected features
5. Split data into training and testing sets
6. Trained Linear Regression model
7. Made predictions
8. Evaluated the model using RMSE and R²
9. Interpreted model coefficients
10. Saved the trained model
11. Tested the saved model

## Files

- `house_price_prediction.ipynb` - Jupyter Notebook
- `house_prices_practice.csv` - Dataset
- `house_price_model.pkl` - Trained Machine Learning model

## Result

The model predicts house prices based on selected housing features.
